GEOQUIZ — GeologyCraft (versión Firebase)
=========================================

A) CONFIGURAR FIREBASE (una sola vez, ~5 minutos, gratis)
  1. Entra a https://console.firebase.google.com con tu cuenta de Google y crea un proyecto
     (por ejemplo "geoquiz"). Google Analytics no hace falta.
  2. Authentication → Comenzar → Sign-in method → activa "Anónimo".
  3. Authentication → Configuración → Dominios autorizados → agrega geologycraft.lol
  4. Realtime Database → Crear base de datos → ubicación "Estados Unidos (us-central1)"
     → empezar en modo bloqueado.
  5. Realtime Database → pestaña Reglas → borra todo, pega el contenido de
     reglas-firebase.json y pulsa Publicar.
  6. ⚙ Configuración del proyecto → General → Tus apps → ícono web (</>) → registra la app
     (sin Hosting). Copia los valores de "firebaseConfig" (apiKey, authDomain, databaseURL,
     projectId, appId) dentro de firebase-config.js.
     Si no aparece databaseURL, cópiala desde la parte de arriba de Realtime Database.

B) SUBIRLO AL SITIO
  Sube la carpeta "geoquiz" completa a la raíz del repositorio geologycraft-web
  (junto a discord/ e invite/). Queda en https://geologycraft.lol/geoquiz/

C) CÓMO SE JUEGA
  1. En el computador del proyector abre geologycraft.lol/geoquiz → "Crear partida".
  2. Los jugadores escanean el QR (o escriben el PIN) y eligen un apodo.
  3. Elige el nivel, si quieres que avance solo y cuántos segundos mostrar
     la respuesta y el ranking. Pulsa "Comenzar".
  4. Cada pregunta se muestra 3 s antes de abrir las alternativas. Cuando responden
     todos los conectados (o se acaba el tiempo) pasa sola a la respuesta, luego al
     ranking animado y luego a la siguiente pregunta.
  Teclado del presentador: Espacio = pausar/continuar, Enter o → = avanzar ya, M = música on/off.
  Expulsar: en el lobby o en el ranking, clic en el nombre y clic otra vez para confirmar.
  La música suena solo en el computador del presentador (botón abajo a la derecha).
  Si se cae o recargas la pestaña del presentador, al volver a "Crear partida"
  aparece la opción "Retomar".

D) EDITAR PREGUNTAS
  Todo está en preguntas.js. Cada pregunta tiene juego (j), nivel, ilustración (t), enunciado,
  respuesta correcta, 3 alternativas incorrectas y una explicación.
  Ilustraciones disponibles para t: amonite, trilobite, volcan, capas, intrusion, piqueta, acido,
  rayador, cristal, lupa, tierra, placas, montana, corriente, clastos, termometro.

Archivos
  index.html            la página
  app.css / app.js      estilos y lógica (presentador y jugadores)
  preguntas.js          banco de preguntas
  ilustraciones.js      dibujos de líneas (amonite, trilobite, etc.) en SVG, sin imágenes
  music.js              música y efectos, sintetizados en vivo (sin archivos de audio)
  firebase-config.js    datos de tu proyecto de Firebase (rellenar)
  reglas-firebase.json  reglas de seguridad para pegar en Realtime Database
  vendor/               Firebase y generador de QR, incluidos localmente
